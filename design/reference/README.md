# Approved UI / UX Reference

This folder contains the user-approved visual target for Forever Racing beginning with V0.3A.

The composite image preserves the two mockups explicitly called out as the desired direction.

## Core visual contract

- Dense browser-MMORPG information layout rather than a generic dashboard.
- Dark charcoal/black surfaces with restrained orange racing accents.
- Thin borders, compact spacing, very small radii and strong hierarchy.
- Cars are prominent game objects, not tiny decorative icons.
- Showroom / Garage / Parts presentation prefers **side-profile pixel art**.
- Racing / PvP / track scenes prefer **top-down pixel art**.
- Missing art is an explicit boxed `? / ART MISSING`, never a fake generic car.
- Car detail views can use larger atmospheric garage/track presentation while remaining data-dense.
- Race presentation should visually connect the car sprites, track, tree, RT, ET and trap speed instead of feeling like an isolated text result.
- Persistent player/build information should remain easy to scan.
- Mobile/foldable layouts should preserve the same visual identity rather than becoming a separate generic mobile design.
